### Project Description
The Human Error Simulator is an intentionally defective web app that transforms everyday user interactions—like typing, clicking, or dragging—into hilarious, inescapable "personality flaws." By subverting standard user experience principles with subtle cursor lags and impossible tasks, it systematically gaslights users into an existential crisis while generating a delightfully sarcastic "Human Error Profile."

### The Problem (that doesn't exist)
Modern software falsely assumes humans are logical, precise, and error-free operators. Traditional UX design tries to prevent human mistakes, leaving people feeling overconfident and dangerously secure in their daily digital choices.

### The Solution (that nobody asked for)
An aggressively judgmental application that pathologizes every physical action you make. By punishing you for typing too fast, moving your mouse too slowly, or failing an impossible slider task, we ensure you never feel confident in front of a computer again.
